# Roadmap-Driven Learning

Turns a planned roadmap into hands-on lessons a learner works through, placing the required theory immediately before each exercise.

## Epics

- **The workbook store, and the renderer that turns lesson markdown into pages** — [#405](https://github.com/sameera/nexus/issues/405)
- **One session teaches one lesson, written on arrival** — [#407](https://github.com/sameera/nexus/issues/407)
- **A roadmap resolves, and an interview establishes the learner's starting point and focus** — [#455](https://github.com/sameera/nexus/issues/455)
- **The rest of the shared component library, and the answer-checking it needs** — [#480](https://github.com/sameera/nexus/issues/480)
- **Concepts are extracted per story, and every slice is marked learner or handoff** — [#456](https://github.com/sameera/nexus/issues/456)
- **The plan is approved at a decision-grade gate and renders as a home page** — [#458](https://github.com/sameera/nexus/issues/458)
- **A stub's sources are pinned when its epic is promoted** — [#459](https://github.com/sameera/nexus/issues/459)
