# Lesson: A harness counterpart epic can be a spec, not a build

The epic sized three stories (S, S, M) for Codex drafting, approval and later-stage reading. All three shipped as test commits in one spec file, because the shared contract from #787 already generated into Codex.

Next time a harness-counterpart epic is planned, check first what the generated output already does. If it already conforms, plan one story that pins it with a spec over the generated skills. Size it S, not three stories.
