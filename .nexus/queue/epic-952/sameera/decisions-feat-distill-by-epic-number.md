## 2026-10-18 — A run refusal names the form the lead used

- **Choice:** The "still in progress" refusal says "this epic" for an epic start and "this pull request" for a `--pr` start. The run record and the marker are the same for both.
- **Why:** G8 keeps the `--pr` refusals as they were, and G5 says both forms refuse each other, so the wording alone changes per form.
- **Refuted alternative:** One shared wording, "this epic", for both forms. It is simpler, but it changes the `--pr` refusal text that G8 freezes.
